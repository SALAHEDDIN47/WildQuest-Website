# WildQuest

## Description
**WildQuest** is an adventure travel website that offers curated trips to breathtaking natural destinations such as jungles, savannas, mountains, and deserts. Our mission is to provide unique, eco-friendly experiences that connect travelers with the beauty of nature.

## Features
- Explore various nature destinations
- Book guided adventure tours
- View trip details, itineraries, and pricing
- Discover wildlife and cultural experiences
- Responsive and user-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript
- React (for frontend development)
- Node.js & Express (for backend services)
- MongoDB (for storing user data and bookings)

## Installation & Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/SALAHEDDIN47/WildQuest-Website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd wildquest
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
